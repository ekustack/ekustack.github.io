Charts in Markdown & docs

Use POST /api/v1/generate-svg (and the official GitHub Action) to embed charts in README files and docs as SVG — no Chart.js, no screenshot service, no image CDN.

Fastest path: fork Figsh/provchart-charts, add repository secret PROVCHART_API_KEY, run the workflow. SVGs appear under docs/charts/ and are committed for you.
Quota: Successful SVG calls share the same monthly pool as HTML generate (limited free test gens when signed up · higher on Pro / Business). See pricing and API docs.

Why SVG for Markdown

  • Portable — works where Markdown allows images or raw HTML
  • No host — ProvChart does not store files; you commit or paste the result
  • Sharp at any zoom — vectors scale in docs sites
  • Same data model — same type, series, axisX as /generate

1. Get an API key

  1. Sign in → Dashboard → Developer API
  2. Create a key (copy once)
  3. Send X-API-Key: pc_live_… on every request

Never commit live keys. Use CI secrets; commit only SVG output.

2. Call generate-svg

curl -s -X POST "https://provchart-api.devtem.org/api/v1/generate-svg" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "type": "line",
    "series": [
      { "name": "Stars", "color": "#8b7bff", "points": [12, 18, 25, 40, 55] }
    ],
    "axisX": ["Jan", "Feb", "Mar", "Apr", "May"],
    "width": 640,
    "height": 280
  }'

Response

{
  "success": true,
  "svg": "<svg xmlns=\"http://www.w3.org/2000/svg\" ...>...</svg>",
  "dataUri": "data:image/svg+xml;base64,..."
}

JavaScript

const res = await fetch("https://provchart-api.devtem.org/api/v1/generate-svg", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": process.env.PROVCHART_API_KEY
  },
  body: JSON.stringify({
    type: "area",
    series: [{ name: "Views", color: "#4fd8c4", points: [10, 25, 40, 55, 48] }],
    axisX: ["Mon", "Tue", "Wed", "Thu", "Fri"],
    width: 640,
    height: 240
  })
});
const data = await res.json();
if (!data.success) throw new Error(data.error);
// data.svg | data.dataUri

3. Embed in Markdown

Option A — Data URI (quick demos)

![Stars over time](data:image/svg+xml;base64,PASTE_FROM_dataUri)

Fine for short SVGs. If the README breaks on long lines, use Option B.

Option B — Commit an .svg file (recommended)

![Stars over time](./docs/charts/stars.svg)

Best for GitHub, GitLab, and most static doc generators.

Option C — Inline HTML (if your engine allows raw HTML)

<!-- Not GitHub README — some docs engines allow: -->
<div>
  <!-- paste data.svg here -->
</div>

4. GitHub Action (recommended for README)

Official action: fscss-ttr/provchart-readme-action · sample to fork: Figsh/provchart-charts

Config — .provchart/charts.json

Top-level array of payloads. Optional file sets the output name.

[
  {
    "file": "demo.svg",
    "type": "area",
    "theme": "midnight",
    "width": 640,
    "height": 320,
    "axisX": ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"],
    "series": [
      {
        "name": "API Requests",
        "color": "#8b7bff",
        "points": [20, 85, 40, 60, 10, 40, 95]
      },
      {
        "name": "Successful Responses",
        "color": "#34d399",
        "points": [15, 80, 38, 46, 6, 35, 79]
      }
    ]
  },
  {
    "file": "health-gauge.svg",
    "type": "gauge",
    "theme": "midnight",
    "width": 220,
    "height": 220,
    "label": "Health",
    "series": [
      { "name": "CPU", "value": 72, "color": "#ff5e7d" },
      { "name": "RAM", "value": 54, "color": "#4fd8c4" },
      { "name": "Disk", "value": 38, "color": "#8b7bff" }
    ]
  }
]

Gauge at 220×220 reads well in README without dominating the page.

Workflow

name: Generate ProvChart README SVGs

on:
  push:
    paths:
      - ".provchart/**"
      - ".github/workflows/charts.yml"
  workflow_dispatch:

permissions:
  contents: write

jobs:
  build-charts:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Generate SVGs
        uses: fscss-ttr/provchart-readme-action@v1.0.4
        with:
          api-key: ${{ secrets.PROVCHART_API_KEY }}
          config: .provchart/charts.json
          output-dir: docs/charts

      - name: Commit generated charts
        uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: "chore: update ProvChart SVGs"
          file_pattern: "docs/charts/*.svg"

5. Dashboard shortcut

Dashboard → Generate Chart SVG: paste key, run payload, copy SVG or data URI. Usage still counts toward the monthly limit.

Supported types

Same as HTML API: line, area, bar, stackedbar, hbar, scatter, combo, gauge. Optional width / height.

When to use HTML instead

  • Product UI / web apps → /api/v1/generate (HTML + CSS)
  • README / MkDocs / Docusaurus assets → /generate-svg
  • Email — SVG support varies; this guide is for docs/Markdown, not email HTML

Troubleshooting

  • Image broken in README — data URI too long; commit a .svg file
  • 401 — check X-API-Key / secret name PROVCHART_API_KEY
  • 403 + “Just a moment…” — Cloudflare bot challenge on the API host; skip bots for /api/*
  • 429 — monthly limit; reduce chart count per run or upgrade
  • Empty chart — ensure series[].points (or gauge value) and matching labels
Security: Repository secrets for keys only. Commit SVG output, never pc_live_ secrets.
