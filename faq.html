General

What is ProvChart?

ProvChart is a pure-CSS chart engine that turns your data into CSS custom properties. The browser paints the chart with native CSS — no chart library is shipped to the page, no hydration delay, and nothing for a crawler to wait on.

How does ProvChart work?

You provide data as numbers. ProvChart compiles it into CSS variables (e.g. --p1: 20%; --p2: 35%;). A clip-path: polygon() reads those variables and draws the shape. After the initial load, no JavaScript is required to display the chart.

What’s the difference between Free, Pro, and Business?

Free: Single-series charts (line, bar, gauge). No sign-up required. 5 API test generations.

Pro ($12/mo): Multi-series charts, all chart types, visual builder, custom themes, Developer API (500 gens/month), priority support.

Business ($29/mo): Everything in Pro + higher API limit (5,000 gens/month) and higher series limits.

See the Pricing page for full details.

Do I need to sign up to use ProvChart?

No for the free builder — generate single-series charts and copy HTML/CSS immediately. You need an account for Pro/Business features, the dashboard, and API keys.

What chart types are supported?

  • Line — Free & Pro
  • Area — Pro
  • Bar / Stacked Bar — Free (single) / Pro (multi)
  • Horizontal Bar — Pro
  • Scatter — Pro
  • Combo (bar + line) — Pro
  • Gauge — Free & Pro

See the Gallery for live examples.

How do I embed a chart on my site?

  1. Generate a chart in the free builder or Pro Dashboard.
  2. Copy the HTML and CSS blocks.
  3. Paste CSS into your stylesheet and HTML where the chart should appear.

Works with any static site generator and platforms that allow HTML (GitHub, Notion, etc.).

Is ProvChart open source?

The rendering core is open source as st-core.fscss (MIT) on GitHub. The hosted service (auth, dashboard, API, billing) is provided by DevTemple.

How do payments work?

Subscriptions are billed monthly via Paystack. You can cancel anytime; access continues until the end of the current period. For billing issues, email provchart@devtem.org.

How is my data handled?

We store account info (email, name) and usage logs (chart type, series count). We do not store the actual data points you send to generate charts. See our Privacy Policy.

Can I update charts with live data?

Yes. Charts return an update() function. Call it with new points and the chart repaints via CSS variables.

chart.update(0, [25, 40, 38, 55, 48]);

Can I customise the look of my charts?

Yes. Use built-in themes (dark, light, midnight) or pass a custom theme object with colors, surface, text, grid, and radius.

Developer API

What is the Developer API?

The Developer API lets you generate pure-CSS charts from your own code. Send JSON with your data → receive { html, css } ready to inject into any page.

Base URL: https://provchart-api.devtem.org/api/v1

Full docs: Developer API reference

How do I create an API key?

  1. Sign in to the Pro Dashboard
  2. Open the Developer API tab
  3. Click Create key and give it a name
  4. Copy the key immediately — it is shown only once

Keys look like: pc_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

How do I revoke an API key?

In the Dashboard → Developer API tab, find the key and click Revoke. The key stops working immediately. You can also call:

DELETE /api/v1/keys/{id} (with your JWT from a logged-in session)

What are the API usage limits?

  • Free: 5 test generations (so you can try the API)
  • Pro: 500 generations / month
  • Business: 5,000 generations / month
  • Enterprise: Custom — contact us

Limits reset on the 1st of each month (UTC). Max series: Pro 12 · Business 50.

How do I check my remaining API usage?

Call:

GET /api/v1/usage with your API key

Or view the usage bar in the Dashboard → Developer API tab.

Response includes used, limit, remaining, and plan.

How do I authenticate API requests?

Send your key in either header:

X-API-Key: pc_live_your_key_here

or

Authorization: Bearer pc_live_your_key_here

What error codes does the API return?

  • INVALID_API_KEY (401) — missing or wrong key
  • PLAN_REQUIRED (403) — Free plan cannot use the full API beyond test gens
  • MONTHLY_LIMIT_REACHED (429) — quota used up for this month
  • INTERNAL_ERROR (500) — unexpected server error

All errors return a clear error message in the JSON body.

Can I see a quick API example?

Yes — minimal example:

const res = await fetch("https://provchart-api.devtem.org/api/v1/generate", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "YOUR_API_KEY"
  },
  body: JSON.stringify({
    type: "line",
    series: [{ name: "Sales", color: "#8b7bff", points: [20, 35, 48, 66] }],
    axisX: ["Jan", "Feb", "Mar", "Apr"]
  })
});
const data = await res.json();
// data.html + data.css

More examples in the docs.

Can I try the API without paying?

Yes. Free accounts get 5 API generations so you can create a key and test the full flow. After that, upgrade to Pro or Business for higher limits.
