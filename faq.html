What is ProvChart?

ProvChart is a pure‑CSS chart engine that turns your data into CSS custom properties. The browser renders the chart using native CSS geometry: no JavaScript chart library is shipped to the page, no hydration delay, and nothing for a crawler to wait on. It's designed for performance, SEO, and simplicity.

How does ProvChart work?

You provide your data as an array of numbers. ProvChart compiles that data into CSS custom properties (e.g., --p1: 20%; --p2: 35%;). The chart uses a clip-path: polygon() that reads those variables directly. The result is a fully styled chart that paints with the page. No JavaScript execution required after the initial load.

What's the difference between Free and Pro?

Free: Single‑series charts only (line, bar, gauge). No sign‑up required. You get the same pure‑CSS rendering and export as Pro, but limited to one data series per chart.

Pro: Unlimited series per chart, all chart types (line, area, bar, stacked bar, horizontal bar, scatter, combo, gauge), custom theming, visual builder dashboard, priority support, and live data template snippets.

See the Pricing page for full details.

Do I need to sign up to use ProvChart?

No. The free builder works without any account. You can generate single‑series charts and copy the HTML/CSS immediately. You only need an account if you want to access Pro features or manage a subscription.

If you do sign up, your account is shared with D‑invites (also by DevTemple), so you can use the same credentials for both services.

What chart types are supported?

ProvChart currently supports 8 chart types:

  • Line: standard line with optional area fill (Pro).
  • Area: filled area with gradient (Pro).
  • Bar (vertical): with optional stacking (Free: single‑series; Pro: multi‑series & stacked).
  • Stacked Bar: cumulative bars (Pro).
  • Horizontal Bar: great for long labels (Pro).
  • Scatter: points with configurable radius (Pro).
  • Combo: mixed bar + line in one chart (Pro).
  • Gauge: circular gauge for KPIs (Free & Pro).

See the Gallery for live examples of each type.

How do I embed a chart on my site?

Every chart generated by ProvChart is self‑contained HTML + CSS. To embed one:

  1. Generate your chart using the free builder or the Pro Dashboard.
  2. Copy the HTML and CSS blocks provided.
  3. Paste the CSS in your <style> or stylesheet, and the HTML wherever you want the chart to appear.

Because it's static HTML and CSS, it works with any static site generator (Astro, Hugo, Jekyll, 11ty, etc.) and can be embedded on GitHub, Notion, or any platform that allows HTML.

Is ProvChart open source?

ProvChart is built on st-core.fscss, an open‑source library (MIT license) maintained by the fscss-ttr organisation. The core rendering engine is free and open for anyone to use, modify, and contribute to.

ProvChart itself (the hosted service with authentication, dashboard, and Pro features) is commercial software provided by DevTemple. The open‑source core powers the charts, while the Pro service adds convenience, support, and advanced features.

You can use the open‑source core directly without a ProvChart account. It's available on GitHub.

How do payments work?

Pro subscriptions are billed monthly via Paystack, a secure payment processor. We accept all major credit cards and bank transfers (for Nigerian users). Prices are shown in USD, but you'll be charged in NGN at the current exchange rate.

Subscriptions auto‑renew at the end of each billing cycle. You can cancel anytime from your account settings. Your Pro access will continue until the end of your current billing period, then your account will revert to Free.

Refunds are not provided for partial months, but if you have a billing issue, contact provchart@devtem.org and we'll help.

How is my data handled?

We take your privacy seriously. We store your email, name, and hashed password (via Supabase). We log usage statistics (which chart types you generate, how many series/points) to improve the service, but we never store the actual chart data you input, only logs of what you used.

All data is transmitted over HTTPS, and we use industry‑standard security practices. For full details, see our Privacy Policy.

Can I update charts with live data?

Yes. Each chart returns an update() function that you can call with new data. The chart repaints itself by writing new values to the same CSS custom properties. No virtual DOM, no re‑mount, just a native CSS transition.

Pro users get a live data template generator in the dashboard. Just paste your endpoint URL and get a ready‑to‑use snippet.

Example:
chart.update(0, [25, 40, 38, 55, 48]);

Can I customise the look of my charts?

Yes. ProvChart supports custom theming. You can pass a theme object to any chart function to override colours, backgrounds, fonts, and border radius.

We also provide three built‑in themes: 'dark' (default), 'light', and 'midnight'. You can choose a theme by setting theme: 'light' or by passing a custom object: 

theme: {
  bg: '#0a0a14',
  surface: '#12101e',
  muted: '#6a6590',
  text: '#e0daf0',
  grid: '#6a65a0',
  radius: '16px'
}
