What actually happens

The render pipeline, in the order it runs.

Not a metaphor. This is the literal sequence the browser executes when your page loads.

01. compile

Your data becomes CSS variables

Each point in your dataset is written once, as --p1 through --pN, on the chart element. Nothing about the shape lives in JavaScript.

02. paint

The browser draws the shape

A clip-path: polygon() reads those variables directly. The line, the fill, the dots — all native CSS geometry, painted on the compositor thread.

03. index

Crawlers see it immediately

There's no hydration step to wait on and no boot time for a charting library. The chart is HTML and CSS from the first response. Fully indexable.

04. update

New data repaints, it doesn't re-render

If you connect live data, JavaScript writes new values to the same variables. The browser interpolates the polygon change natively. No virtual DOM, no re-mount.
