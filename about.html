About

Charts without the JavaScript tax

ProvChart is a pure CSS charting engine that compiles data into CSS custom properties instead of shipping a heavy JavaScript runtime. Charts render on the first paint, stay light, and stay crawlable — with an optional Developer API and SVG export when you need automation.

Core idea

Most chart libraries trade beauty for 40–150 kb of JavaScript, hydration delay, and content that search engines often miss on the first crawl.

ProvChart takes the opposite path. Your data becomes CSS variables. The browser paints the shape with native CSS. No chart library runs on the page.

No JS chart runtime

We don’t ship a charting library to the browser. The page stays light.

CSS custom properties

Data points compile into variables such as --p1, --p2, … that drive the visual.

Native browser paint

Shapes use CSS (including clip-path). The compositor does the work.

SEO-friendly

Charts are real HTML and CSS from the first response — indexable on the first crawl.

SVG when you need it

The same pipeline can emit SVG and a data URI for README and docs — no third-party image host.

What you get

  • Free builder — single-series line, bar, and gauge at /get-started (no login required)
  • Signed-up free tier — 5 API generations / month to test keys against the live API
  • Pro Dashboard — multi-series, all chart types, themes, adaptive builder, SVG Export tab

  • Guides — accessibility, static embeds, and more at /guides

Developer API

The Developer API lets your backend or frontend generate charts dynamically. You send data; you get pure HTML and CSS (or SVG). Those charts still render with zero kilobytes of charting JavaScript on the page.

POST https://provchart-api.devtem.org/api/v1/generate → html + css
POST https://provchart-api.devtem.org/api/v1/generate-svg → svg + dataUri

Both endpoints share one monthly pool: 5 (free, signed up) · 500 (Pro) · 5,000 (Business). Create keys in the Pro Dashboard.

Who it’s for

  • Teams that care about performance (LCP, bundle size, first paint)
  • Sites that need crawlable chart content
  • Static and mostly-static pages that still want real visualizations
  • Developers and agents generating charts from a backend without a client chart library

Open source core

The rendering approach builds on st-core.fscss (MIT), maintained by fscss-ttr. The hosted product — dashboard, auth, billing, and API — is provided by DevTemple.
