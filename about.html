About

Charts without the JavaScript tax

ProvChart is a pure CSS charting engine that compiles data into CSS custom properties instead of shipping a heavy JavaScript runtime. The result: charts that render on the first paint, weigh almost nothing, and are fully crawlable.

Core idea

Most chart libraries force a trade-off: beautiful charts in exchange for 40–150 kb of JavaScript, a hydration delay, and content that search engines often struggle to see on the first crawl.

ProvChart takes the opposite path. Your data becomes CSS variables. The browser paints the shape with native CSS. No chart library runs on the page.

No JS runtime

We don’t ship a charting library to the browser. The page stays light.

CSS custom properties

Data points compile into variables such as --p1, --p2, … that drive the visual.

Native browser paint

Shapes are drawn with CSS (including clip-path). The compositor does the work.

SEO-friendly

Charts are real HTML and CSS from the first response — fully indexable on the first crawl.

Developer API

The Developer API lets your backend or frontend generate charts dynamically. You send data; you get back pure HTML and CSS. Those charts still render with zero kilobytes of charting JavaScript on the page.

Free accounts get a small number of test generations. Pro and Business unlock higher monthly limits so you can wire ProvChart into products, dashboards, and automated reports.

Who it’s for

  • Teams that care about performance (LCP, bundle size, first paint)
  • Sites that need crawlable chart content
  • Static and mostly-static pages that still want real data visualizations
  • Developers who want to generate charts from a backend without shipping a client-side chart library

Open source core

The rendering engine is built on st-core.fscss (MIT), maintained by fscss-ttr. ProvChart (the hosted product, dashboard, and API) is provided by DevTemple.

Get started

Use the free visual builder with no sign-up, or create an API key from the dashboard and generate charts from your own code.
