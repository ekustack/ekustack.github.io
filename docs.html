Overview

ProvChart is a pure-CSS chart engine. Data becomes CSS custom properties; the browser paints geometry with native CSS (clip-path, bars, gauges). After generation there is no chart-library runtime on the page.

ProvChart st-core.fscss fscss-ttr DevTemple

Product surface: free builder at /get-started, Pro Dashboard (adaptive builder + SVG tab + keys), Developer API at https://provchart-api.devtem.org.

Who this is for

  • Teams that care about first paint, SEO, and Core Web Vitals
  • Static sites and docs that need charts without client chart JS
  • Products that generate charts from backends or agents via API

Quick start

Option A — Free visual builder

Open /get-started, enter one series, copy HTML + CSS. No account.

Option B — Developer API

const res = await fetch("https://provchart-api.devtem.org/api/v1/generate", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "YOUR_API_KEY"
  },
  body: JSON.stringify({
    type: "line",
    series: [
      { name: "Revenue", color: "#8b7bff", points: [20, 35, 45, 30, 50] }
    ],
    axisX: ["Jan", "Feb", "Mar", "Apr", "May"]
  })
});
const data = await res.json();
if (data.success) {
  document.getElementById("chart").innerHTML = data.html;
  document.head.insertAdjacentHTML("beforeend", `<style>${data.css}</style>`);
}
Replace YOUR_API_KEY with a key from Dashboard → Developer API. Free accounts get limited test generations; Pro/Business raise monthly limits.

Installation

For production embeds, prefer the API or dashboard export (static HTML/CSS). Client ESM builds may not match your host; the API always returns current output.

CDN (if available)

<script src="https://cdn.jsdelivr.net/gh/fscss-ttr/ProvChart@main/core.js"></script>

Open-source core

Rendering ideas and FSCSS core: st-core.fscss.

Core concepts

  1. Compile — points become CSS variables on a chart root.
  2. Paint — clip-path, bar heights, or gauge rings draw the shape.
  3. Index — HTML/CSS ship in the first response (SEO-friendly).
  4. Update — optional JS only rewrites variables, or regenerate via API.

Values are typically on a 0–100 scale (100 ≈ top of the plot). Normalize upstream if your data uses other units.

line() Free Pro

Multi-series line. Optional fill via area().

ProvChart.line({
  series: [
    { name: "Revenue", color: "#8b7bff", points: [20, 35, 45, 30, 50] },
    { name: "Cost", color: "#4fd8c4", points: [15, 28, 30, 22, 40] }
  ],
  axisX: ["Jan", "Feb", "Mar", "Apr", "May"],
  theme: "midnight" // or { surface, text, muted, ... }
});

area() Pro

Filled series (same payload shape as line).

ProvChart.area({
  series: [{ name: "Traffic", color: "#4fd8c4", points: [20, 55, 40, 85, 60] }],
  axisX: ["Mon", "Tue", "Wed", "Thu", "Fri"]
});

bar() Free Pro

Vertical bars. Prefer series + axisX (API shape).

ProvChart.bar({
  series: [
    { name: "2025", color: "#8b7bff", points: [55, 62, 48, 70] },
    { name: "2026", color: "#4fd8c4", points: [40, 58, 72, 65] }
  ],
  axisX: ["Q1", "Q2", "Q3", "Q4"],
  stacked: false
});

hbar() Pro

Horizontal bars. Prefer series[0].points + axisX labels.

ProvChart.hbar({
  series: [{ name: "Skill", color: "#8b7bff", points: [95, 88, 90, 72] }],
  axisX: ["HTML", "CSS", "JS", "SVG"]
});
// Legacy: bars: [{ label, value, color }, ...]

Stacked bar Pro

API: type: "stackedbar" or core bar({ stacked: true }).

// API body
{
  "type": "stackedbar",
  "series": [
    { "name": "Product", "color": "#8b7bff", "points": [30, 40, 35, 50] },
    { "name": "Services", "color": "#4fd8c4", "points": [20, 25, 30, 22] }
  ],
  "axisX": ["Jan", "Feb", "Mar", "Apr"]
}

scatter() Pro

ProvChart.scatter({
  series: [
    { name: "A", color: "#ff5e7d", points: [20, 45, 30, 60, 40], radius: 5 }
  ],
  axisX: ["1", "2", "3", "4", "5"]
});

combo() Pro

ProvChart.combo({
  series: [
    { name: "Sales", type: "bar", color: "#8b7bff", points: [30, 40, 35, 50] },
    { name: "Trend", type: "line", color: "#4fd8c4", points: [28, 38, 33, 48] }
  ],
  axisX: ["Q1", "Q2", "Q3", "Q4"]
});

gauge() Free Pro

Single ring: value + color. Multi-ring: series: [{ name, value, color }].

// Multi-ring
ProvChart.gauge({
  size: 180,
  thickness: 10,
  label: "Health",
  series: [
    { name: "CPU", value: 72, color: "#ff5e7d" },
    { name: "RAM", value: 54, color: "#4fd8c4" },
    { name: "Disk", value: 38, color: "#8b7bff" }
  ]
});

stat()

ProvChart.stat({
  label: "Total revenue",
  value: "$12,450",
  delta: "+12.5%"
});

combine()

const a = ProvChart.line({ ... });
const b = ProvChart.gauge({ ... });
const bundle = ProvChart.combine([a, b]);
// bundle.html, bundle.css

update()

When the engine returns an update function, rewrite points without regenerating markup:

const chart = ProvChart.line({ ... });
// inject chart.html / chart.css
chart.update(0, [25, 40, 38, 55, 48]); // series index, new points

API-generated static HTML has no live update unless you also ship a small variable-writer script.

Developer API Pro / Business

Base URL: https://provchart-api.devtem.org/api/v1

  • POST /generate → HTML + CSS
  • POST /generate-svg → SVG + data URI
  • GET /usage → plan, used, limit, remaining

Both generate endpoints share the same monthly quota.

Authentication

  1. Sign in → Pro Dashboard → Developer API
  2. Create key (shown once)
  3. Send on every request:
X-API-Key: pc_live_xxxxxxxx
// or
Authorization: Bearer pc_live_xxxxxxxx
Never ship live keys in public client bundles. Proxy through your server or CI.

POST /api/v1/generate

FieldTypeRequiredDescription
typestringYes line, area, bar, stackedbar, hbar, scatter, combo, gauge
seriesarrayYes* Series objects; required for most types
axisXarrayNo Category labels
themestring | objectNo dark | light | midnight or overrides
stackedbooleanNo For bar layouts
label / size / thickness—No Gauge options

Series item

{
  "name": "Revenue",
  "color": "#8b7bff",
  "points": [20, 35, 45],
  "type": "bar",      // combo only
  "radius": 5,        // scatter
  "value": 78         // gauge ring
}

POST /api/v1/generate-svg

Same chart body as /generate, plus optional width (default 640, max 1200) and height (default 320, max 800).

{
  "success": true,
  "svg": "<svg xmlns=\"http://www.w3.org/2000/svg\" ...>...</svg>",
  "dataUri": "data:image/svg+xml;base64,..."
}

No storage, no third-party image host. Ideal for README and docs.

GET /api/v1/usage

{
  "plan": "pro",
  "used": 42,
  "limit": 500,
  "remaining": 458,
  "month": "2026-08"
}

API keys

  • Create / list / revoke in Dashboard → Developer API
  • Treat keys as secrets; rotate if leaked
  • Revoked keys return INVALID_API_KEY

Response shape

HTML success

{ "success": true, "html": "...", "css": "..." }

Error

{ "success": false, "error": "Human message", "code": "MONTHLY_LIMIT_REACHED" }

Integration pattern

Server or build holds the key → calls ProvChart → returns html/css or svg to the client or writes files at build time.

Next.js

// app/api/chart/route.ts
export async function POST(req: Request) {
  const body = await req.json();
  const res = await fetch("https://provchart-api.devtem.org/api/v1/generate", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-API-Key": process.env.PROVCHART_API_KEY!,
    },
    body: JSON.stringify(body),
  });
  const data = await res.json();
  return Response.json(data, { status: res.status });
}

Astro / SSG

Call the API in a build script or server endpoint; inject returned HTML/CSS into the page partial. Charts need no client chart library at runtime.

Node / Python

# Python
import os, requests
r = requests.post(
  "https://provchart-api.devtem.org/api/v1/generate",
  headers={"X-API-Key": os.environ["PROVCHART_API_KEY"]},
  json={"type": "bar", "series": [{"points": [40, 55, 48], "color": "#8b7bff"}], "axisX": ["A", "B", "C"]},
)
print(r.json().get("html"))

Theming

  • "dark" (default), "light", "midnight"
  • Or object: bg, surface, muted, text, grid, radius

Live data

Prefer regenerating via API when data changes, or use core update() when you control the engine bundle. Variable-only updates avoid re-shipping a chart library.

Embedding

  1. Generate (builder, dashboard, or API)
  2. Paste CSS into <style> or stylesheet
  3. Paste HTML where the chart should appear

Works with Astro, Hugo, 11ty, Jekyll, plain HTML, and most frameworks.

Troubleshooting

Bar empty / wrong

Use series[].points + axisX. Align series lengths when possible.

Hbar layout

Labels from axisX; values from first series points (or legacy bars).

ESM import fails

Use API/dashboard static output instead of client ESM.

429 limit

Check GET /usage; upgrade plan or wait for monthly reset.

401 key

Key revoked, typo, or wrong header name.

For AI agents

  • Base: https://provchart-api.devtem.org/api/v1
  • Auth: X-API-Key
  • HTML: POST /generate → html, css
  • SVG: POST /generate-svg → svg, dataUri
  • Points 0–100 scale; max 200 points per series
  • Do not retry 401/429 without new credentials or backoff
{
  "name": "provchart_generate",
  "method": "POST",
  "url": "https://provchart-api.devtem.org/api/v1/generate",
  "headers": {
    "Content-Type": "application/json",
    "X-API-Key": "{{PROVCHART_API_KEY}}"
  },
  "body_schema": {
    "type": "line|area|bar|stackedbar|hbar|scatter|combo|gauge",
    "series": [{ "name": "string", "color": "#hex", "points": [0] }],
    "axisX": ["string"]
  }
}

ProvChart Runtime

Optional client script that enhances HTML/CSS charts with animation, tooltips, and legend focus. It does not replace the core engine and does not run on pure SVG from generate-svg. 

<script>
  window.ProvChartRuntimeConfig = { tooltips: true, perPointTooltips: true };
</script>
<script src="https://cdn.jsdelivr.net/npm/provchart-runtime@1.0.0/dist/provchart-runtime.min.js" defer></script>
  • GitHub
  • npm
  • CDN: jsDelivr / unpkg

After SPA injects: ProvChartRuntime.refresh(). Homepage and gallery ship with the runtime enabled.
