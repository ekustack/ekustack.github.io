Overview

ProvChart is a pure‑CSS chart engine that compiles your data into CSS custom properties. The browser paints the shape — no chart library ships to the page, no hydration delay, nothing for a crawler to wait on. we're releasing our pro API soon.

ProvChart by DevTemple st-core.fscss open source fscss-ttr DevTemple

ProvChart is built on top of st-core.fscss — an open‑source library for CSS‑native chart rendering. The core is maintained by fscss-ttr, while DevTemple provides the Pro workflow, authentication, and commercial support.

Who this is for

  • Developers who want charts that render with the page, no JS libraries.
  • SEO‑focused teams who need fully indexable chart content.
  • Static site builders who want embedded charts without runtime bloat.
  • Dashboards that need live data updates without re‑rendering.

Quick start

Generate your first chart with a single function call:

// Import the core (ES module)
import ProvChart from 'https://cdn.jsdelivr.net/gh/fscss-ttr/ProvChart@main/core.esm.js';

const chart = ProvChart.line({
  series: [
    { name: 'Revenue', color: '#8b7bff', points: [20, 35, 45, 30, 50] }
  ],
  axisX: ['Jan', 'Feb', 'Mar', 'Apr', 'May']
});

// Drop the HTML and CSS anywhere
document.getElementById('chart-container').innerHTML = chart.html;
document.querySelector('head').insertAdjacentHTML('beforeend', `<style>${chart.css}</style>`);

Or use the free visual builder to generate code without writing any.

Installation

CDN (browser)

ES Module (modern)

npm

npm install provchart-core
import ProvChart from 'provchart-core';

Note: ProvChart is a wrapper around the open‑source st-core.fscss library. You can use the core directly if you prefer, but ProvChart adds a simpler API and additional chart types.

line() Free Pro

Draws a line chart with optional area fill.

Parameters

NameTypeDefaultDescription
seriesArrayrequiredArray of series objects: { name, color, points }
axisXArrayundefinedLabels for the X‑axis
themeObjectdarkTheme overrides
widthstring'100%'Chart width
heightnumber220Chart height in pixels

Example

const chart = ProvChart.line({
  series: [
    { name: 'Sales', color: '#8b7bff', points: [30, 45, 28, 60, 55] },
    { name: 'Target', color: '#4fd8c4', points: [25, 40, 30, 55, 50] }
  ],
  axisX: ['Q1', 'Q2', 'Q3', 'Q4', 'Q5'],
  theme: { surface: '#1a1628' }
});

area() Pro

Line chart with a filled area gradient beneath the line.

Same parameters as line().

const chart = ProvChart.area({
  series: [{ name: 'Revenue', color: '#8b7bff', points: [20, 35, 45, 30, 50] }],
  axisX: ['Jan', 'Feb', 'Mar', 'Apr', 'May']
});

bar() Free Pro

Vertical bar chart. Supports stacking when stacked: true.

Parameters

NameTypeDefaultDescription
seriesArrayrequiredArray of series objects with points
stackedbooleanfalseIf true, bars are stacked
axisXArrayundefinedX‑axis labels

Example

const chart = ProvChart.bar({
  series: [
    { name: 'Product A', color: '#8b7bff', points: [30, 40, 35] },
    { name: 'Product B', color: '#4fd8c4', points: [20, 25, 30] }
  ],
  axisX: ['Jan', 'Feb', 'Mar'],
  stacked: true
});

hbar() Pro

Horizontal bar chart – better for long category labels.

Parameters

NameTypeDefaultDescription
barsArrayrequiredArray of { label, value, color }
themeObjectdarkTheme overrides

Example

const chart = ProvChart.hbar({
  bars: [
    { label: 'Very long label 1', value: 85, color: '#8b7bff' },
    { label: 'Very long label 2', value: 62, color: '#4fd8c4' },
    { label: 'Very long label 3', value: 43, color: '#f0a860' }
  ]
});

stackedBar() Pro

Alias for bar() with stacked: true. Convenience wrapper.

const chart = ProvChart.stackedBar({
  series: [
    { name: 'A', color: '#8b7bff', points: [30, 40, 35] },
    { name: 'B', color: '#4fd8c4', points: [20, 25, 30] },
    { name: 'C', color: '#f0a860', points: [15, 20, 25] }
  ],
  axisX: ['Jan', 'Feb', 'Mar']
});

scatter() Pro

Scatter plot with configurable point radius.

Parameters

NameTypeDefaultDescription
seriesArrayrequiredSeries with points and radius
axisXArrayundefinedX‑axis labels

Example

const chart = ProvChart.scatter({
  series: [
    { name: 'Data points', color: '#8b7bff', points: [20, 35, 45, 30, 50], radius: 6 }
  ],
  axisX: ['A', 'B', 'C', 'D', 'E']
});

combo() Pro

Mixed chart – each series can have its own type ('line' or 'bar').

Example

const chart = ProvChart.combo({
  series: [
    { name: 'Sales', type: 'bar', color: '#8b7bff', points: [30, 40, 35, 50] },
    { name: 'Trend', type: 'line', color: '#4fd8c4', points: [28, 38, 33, 48] }
  ],
  axisX: ['Q1', 'Q2', 'Q3', 'Q4']
});

gauge() Free Pro

Circular gauge for single‑value KPIs.

Parameters

NameTypeDefaultDescription
valuenumberrequiredValue between 0–100
colorstring'#8b7bff'Gauge color
sizenumber140Size in pixels
thicknessnumber12Ring thickness

Example

const chart = ProvChart.gauge({
  value: 78,
  color: '#4fd8c4',
  size: 160,
  thickness: 14
});

stat() Free Pro

Simple stat card with label, value, and optional delta.

Example

const chart = ProvChart.stat({
  label: 'Total revenue',
  value: '$12,450',
  delta: '+12.5%'
});

combine() Free Pro

Combine multiple chart outputs into one HTML/CSS bundle.

Example

const line = ProvChart.line({ ... });
const gauge = ProvChart.gauge({ ... });
const combined = ProvChart.combine([line, gauge]);

// combined.html – both charts HTML
// combined.css – both charts CSS

Theming

ProvChart ships with three built‑in themes. You can also provide custom overrides.

Built‑in themes

  • 'dark' – deep purple/black (default)
  • 'light' – light surface for white backgrounds
  • 'midnight' – even darker, cooler tones

Custom theme

ProvChart.line({
  series: [ ... ],
  theme: {
    bg: '#0a0a14',
    surface: '#12101e',
    muted: '#6a6590',
    text: '#e0daf0',
    grid: '#6a65a0',
    radius: '16px'
  }
});

Live data Pro

ProvChart charts are updatable by writing new values to the same CSS custom properties.

Each chart returns an update() function:

const chart = ProvChart.line({ ... });

// Later, update with new data
chart.update(0, [25, 40, 38, 55, 48]);
// ^ series index 0, new points

// Or use the live data template:
const template = `
fetch('YOUR_API_ENDPOINT')
  .then(r => r.json())
  .then(data => {
    const points = data.map(v => v * 100);
    chart.update(0, points);
  });
`;

Pro users get a live data template generator in the dashboard – just paste your endpoint URL and get a ready‑to‑use snippet.

Embedding

ProvChart charts are self‑contained HTML + CSS. Embed them anywhere:

1. Copy the generated HTML and CSS

Use the free builder or the Pro Dashboard to generate your chart, then copy the HTML and CSS blocks.

2. Paste into your page

  • Paste the CSS in your <style> or stylesheet.
  • Paste the HTML wherever you want the chart to appear.

3. For static sites

The chart is static HTML and CSS – works with any static site generator (Astro, Hugo, Jekyll, 11ty, etc.)

4. For dynamic updates

Keep the update() function reference and call it with new data.
