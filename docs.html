Overview

ProvChart is a pure-CSS chart engine that compiles your data into CSS custom properties. The browser paints the shape — no chart library ships to the page, no hydration delay, nothing for a crawler to wait on.

ProvChart by DevTemple st-core.fscss open source fscss-ttr DevTemple

ProvChart is built on top of st-core.fscss — an open-source library for CSS-native chart rendering. The core is maintained by fscss-ttr, while DevTemple provides the Pro workflow, authentication, Developer API, and commercial support.

Who this is for

  • Developers who want charts that render with the page, no JS libraries.
  • SEO-focused teams who need fully indexable chart content.
  • Static site builders who want embedded charts without runtime bloat.
  • Dashboards & products that need to generate charts via API.

Quick start

Generate your first chart with a single function call:

// Import the core (ES module)
import ProvChart from 'https://cdn.jsdelivr.net/gh/fscss-ttr/ProvChart@main/core.esm.js';

const chart = ProvChart.line({
  series: [
    { name: 'Revenue', color: '#8b7bff', points: [20, 35, 45, 30, 50] }
  ],
  axisX: ['Jan', 'Feb', 'Mar', 'Apr', 'May']
});

document.getElementById('chart-container').innerHTML = chart.html;
document.querySelector('head').insertAdjacentHTML('beforeend', `<style>${chart.css}</style>`);

Or use the free visual builder to generate code without writing any.

Developer API Pro / Business

The ProvChart Developer API lets you generate pure-CSS charts from your own backend or frontend. You send data → we return ready-to-use html + css.

Base URL:
https://provchart-api.devtem.org/api/v1

Who can use it?

  • Pro – 500 generations / month
  • Business – 5,000 generations / month
  • Enterprise – contact provchart@devtem.org

Authentication

All Developer API requests require an API Key.

How to get an API Key

  1. Go to the Pro Dashboard
  2. Open the Developer API tab
  3. Click Create key
  4. Copy the key immediately (it is shown only once)

How to send the key

Use either header:

// Recommended
X-API-Key: pc_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

// Also accepted
Authorization: Bearer pc_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

POST /api/v1/generate

Generate a chart and receive pure HTML + CSS.

Request body

FieldTypeRequiredDescription
type string Yes One of:
line, area, bar, stackedbar, hbar, scatter, combo, gauge
series array Yes* Array of series objects (see below). Required for most chart types.
axisX array No Labels for the X-axis
theme object | string No "dark", "light", "midnight" or custom object
stacked boolean No Only for bar charts

Series object

{
  "name": "Revenue",
  "color": "#8b7bff",
  "points": [20, 35, 48, 66, 52],
  "type": "line",          // only for combo charts
  "stack": true,           // only for stacked bars
  "radius": 6              // only for scatter
}

Successful response

{
  "success": true,
  "html": "<div class=\"pc-...\">...</div>",
  "css": ".pc-... { ... }"
}

Check your current monthly usage.

{

Managing API Keys

All key management is done from the Pro Dashboard → Developer API tab.

  • Create key – generates a new key (shown only once)
  • List keys – shows name, prefix, creation date, last used
  • Revoke key – immediately disables the key

You can also manage keys programmatically (requires a logged-in JWT):

// Create
POST /api/v1/keys
{ "name": "Production" }

// List
GET /api/v1/keys

// Revoke
DELETE /api/v1/keys/{id}

Examples

Node.js / Fetch

const res = await fetch("https://provchart-api.devtem.org/api/v1/generate", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "pc_live_YOUR_KEY_HERE"
  },
  body: JSON.stringify({
    type: "line",
    series: [
      { name: "Revenue", color: "#8b7bff", points: [20, 35, 48, 66] },
      { name: "Users", color: "#4fd8c4", points: [12, 28, 41, 55] }
    ],
    axisX: ["Jan", "Feb", "Mar", "Apr"]
  })
});

const data = await res.json();

if (data.success) {
  console.log(data.html);
  console.log(data.css);
} else {
  console.error(data.error);
}

cURL

curl -X POST https://provchart-api.devtem.org/api/v1/generate \
  -H "Content-Type: application/json" \
  -H "X-API-Key: pc_live_YOUR_KEY_HERE" \
  -d '{
    "type": "gauge",
    "series": [{ "points": [78], "color": "#4fd8c4" }]
  }'

line() Free Pro

Draws a multi-series line chart with optional area fill.

Parameters

NameTypeDefaultDescription
series Array required Array of series objects: { name, color, points }
axisX Array undefined Labels for the X-axis
theme Object | string "dark" Theme name or custom theme object
width string "100%" Chart width
height number 220 Chart height in pixels

Example

const chart = ProvChart.line({
  series: [
    { name: "Sales", color: "#8b7bff", points: [30, 45, 28, 60, 55] },
    { name: "Target", color: "#4fd8c4", points: [25, 40, 30, 55, 50] }
  ],
  axisX: ["Jan", "Feb", "Mar", "Apr", "May"]
});

area() Pro

Same as line() but with a filled area under the line by default.

Example

const chart = ProvChart.area({
  series: [
    { name: "Users", color: "#8b7bff", points: [12, 28, 35, 42, 58] }
  ],
  axisX: ["Mon", "Tue", "Wed", "Thu", "Fri"]
});

bar() Free Pro

Vertical bar chart. Supports stacking.

Parameters

NameTypeDefaultDescription
series Array required Array of series objects
stacked boolean false Stack all series on top of each other
axisX Array undefined X-axis labels

Example

const chart = ProvChart.bar({
  series: [
    { name: "Product A", color: "#8b7bff", points: [40, 55, 30, 70] },
    { name: "Product B", color: "#4fd8c4", points: [25, 35, 45, 50] }
  ],
  axisX: ["Q1", "Q2", "Q3", "Q4"],
  stacked: false
});

hbar() Pro

Horizontal bar chart. Useful for rankings and comparisons.

Example

const chart = ProvChart.hbar({
  bars: [
    { label: "Chrome", value: 65, color: "#8b7bff" },
    { label: "Firefox", value: 18, color: "#4fd8c4" },
    { label: "Safari", value: 12, color: "#f0a860" },
    { label: "Edge", value: 5, color: "#ff5e7d" }
  ]
});

stackedBar() Pro

Convenience wrapper for bar({ stacked: true }).

Example

const chart = ProvChart.stackedBar({
  series: [
    { name: "A", color: "#8b7bff", points: [30, 40, 35] },
    { name: "B", color: "#4fd8c4", points: [20, 25, 30] },
    { name: "C", color: "#f0a860", points: [15, 20, 25] }
  ],
  axisX: ["Jan", "Feb", "Mar"]
});

scatter() Pro

Scatter plot with configurable point radius.

Parameters

NameTypeDefaultDescription
series Array required Series with points and optional radius
axisX Array undefined X-axis labels

Example

const chart = ProvChart.scatter({
  series: [
    { name: "Data points", color: "#8b7bff", points: [20, 35, 45, 30, 50], radius: 6 }
  ],
  axisX: ["A", "B", "C", "D", "E"]
});

combo() Pro

Mixed chart – each series can have its own type (line or bar).

Example

const chart = ProvChart.combo({
  series: [
    { name: "Sales", type: "bar", color: "#8b7bff", points: [30, 40, 35, 50] },
    { name: "Trend", type: "line", color: "#4fd8c4", points: [28, 38, 33, 48] }
  ],
  axisX: ["Q1", "Q2", "Q3", "Q4"]
});

gauge() Free Pro

Circular gauge for single-value KPIs.

Parameters

NameTypeDefaultDescription
value number required Value between 0–100
color string "#8b7bff" Gauge color
size number 140 Size in pixels
thickness number 12 Ring thickness

Example

const chart = ProvChart.gauge({
  value: 78,
  color: "#4fd8c4",
  size: 160,
  thickness: 14
});

stat() Free Pro

Simple stat card with label, value, and optional delta.

Example

const chart = ProvChart.stat({
  label: "Total revenue",
  value: "$12,450",
  delta: "+12.5%"
});

combine() Free Pro

Combine multiple chart outputs into one HTML/CSS bundle.

Example

const line = ProvChart.line({ ... });
const gauge = ProvChart.gauge({ ... });

const combined = ProvChart.combine([line, gauge]);

// combined.html  → both charts HTML
// combined.css   → both charts CSS

Theming

ProvChart ships with three built-in themes. You can also provide custom overrides.

Built-in themes

  • "dark" – deep purple/black (default)
  • "light" – light surface for white backgrounds
  • "midnight" – even darker, cooler tones

Custom theme

ProvChart.line({
  series: [ ... ],
  theme: {
    bg: "#0a0a14",
    surface: "#12101e",
    muted: "#6a6590",
    text: "#e0daf0",
    grid: "#6a65a0",
    radius: "16px"
  }
});

Live data Pro

ProvChart charts are updatable by writing new values to the same CSS custom properties.

Each chart returns an update() function:

const chart = ProvChart.line({ ... });

// Later, update with new data
chart.update(0, [25, 40, 38, 55, 48]);
// ^ series index 0, new points

Pro users also get a live data template generator in the dashboard — just paste your endpoint URL and get a ready-to-use snippet.

Embedding

ProvChart charts are self-contained HTML + CSS. Embed them anywhere:

1. Copy the generated HTML and CSS

Use the free builder or the Pro Dashboard to generate your chart, then copy the HTML and CSS blocks.

2. Paste into your page

  • Paste the CSS in your <style> or stylesheet.
  • Paste the HTML wherever you want the chart to appear.

3. For static sites

The chart is static HTML and CSS — works with any static site generator (Astro, Hugo, Jekyll, 11ty, etc.).

4. For dynamic updates

Keep the update() function reference and call it with new data.
