Charts.css MIT

Charts.css is an open-source pure CSS framework for data visualization. It turns semantic HTML <table> elements into charts using utility classes and CSS custom properties — no JavaScript required.

  • Official site: chartscss.org
  • GitHub: ChartsCSS/charts.css
  • License: MIT · \~76 kb (\~7 kb gzipped) · no dependencies
chartscss.org GitHub
This page is a concise reference hosted by ProvChart for convenience. For the most up-to-date details, always check the official documentation.

npm / yarn

npm install charts.css
# or
yarn add charts.css
import 'charts.css';

Download

From GitHub releases → use dist/charts.min.css.

Basic structure

Wrap the chart (recommended) and use a semantic table:

<div id="my-chart">
  <table class="charts-css [chart-type] [component-classes]">
    <caption>Chart Heading</caption>
    <thead>...</thead> <!-- optional -->
    <tbody>
      <tr>
        <th scope="row">Label</th>
        <td style="--size: 0.4"><span class="data">$40K</span></td>
      </tr>
      <!-- more rows -->
    </tbody>
  </table>
  <ul class="charts-css legend">...</ul> <!-- optional -->
</div>
  • Data values use unitless numbers 0–1 via --size (the framework multiplies by 100% or 360deg depending on chart type).
  • For area/line charts, also use --start (and sometimes --end).
  • Wrap visible data text in <span class="data"> when needed.

Layers / anatomy

  • Heading — <caption>
  • Labels — <th>
  • Data — <td>
  • Axes — generated from <tbody> / borders

Only <tbody> + <td> are strictly required for basic charts.

Customization

  • Scope styles with a wrapper id (e.g. #my-chart .column { ... }).
  • Style any inner element (caption, tbody, th, td, …) with normal CSS.
  • Supports animations (@keyframes), 3D effects, motion, and media queries for responsiveness.
