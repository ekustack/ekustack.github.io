Highcharts Commercial

Highcharts is a commercial JavaScript/TypeScript charting library (SVG-based, with some Canvas/WebGL) for interactive, responsive, and accessible charts.

  • Official site: highcharts.com
  • API: api.highcharts.com
  • Docs: highcharts.com/docs
  • Current core version: \~v13.x (as of 2026)
highcharts.com API reference Demos
Highcharts requires a commercial license for production use. This page is a concise overview only. The complete, searchable reference is at api.highcharts.com.

Installation

CDN (demos / prototypes)

<script src="https://code.highcharts.com/highcharts.js"></script>
<!-- Modules e.g. -->
<script src="https://code.highcharts.com/modules/exporting.js"></script>
<script src="https://code.highcharts.com/modules/accessibility.js"></script>

npm

npm install highcharts --save
import Highcharts from 'highcharts';
// or Highstock / Highmaps / Gantt
import Highcharts from 'highcharts/highstock';
import 'highcharts/modules/exporting';

ES modules and TypeScript declarations included. Self-host from the official download or GitHub. Commercial license required for production.

Basic usage

Highcharts.chart('container', {
  chart: { type: 'line' },
  title: { text: 'My Chart' },
  subtitle: { text: 'Optional' },
  xAxis: { categories: ['A', 'B', 'C'] },
  yAxis: { title: { text: 'Values' } },
  series: [{
    name: 'Series 1',
    data: [1, 3, 2, 4]
  }]
});
  • Constructor: Highcharts.chart(renderTo, options [, callback])
  • Also: stockChart, mapChart, ganttChart
  • Global defaults: Highcharts.setOptions({ ... })

Core configuration structure

Top-level keys on the options object:

SectionPurpose
chartType, size, background, animation, events, zoom, styledMode, …
title / subtitle / captionText elements
xAxis / yAxis / zAxis / colorAxisAxes (linear, log, datetime, category, bands, lines, …)
seriesArray of series (data + type-specific options)
plotOptionsDefaults for all series or per type
legendVisibility, layout, style
tooltipHover tooltips (formatter, shared, …)
creditsCredit link
exportingExport menu (module)
responsiveRules for different screen sizes
accessibilityA11y options (module)
colors / paletteColor arrays / palette (v13+)
langLocalization
timeTimezone / date handling

Series data formats

  • Numbers: [1, 2, 3]
  • Arrays: [[x, y], ...] or [name, y]
  • Objects: [{ x, y, name, color, ... }, ...]

Full tree: api.highcharts.com/highcharts

Main series / chart types

Common core types (via chart.type or series.type):

  • Line / Spline / Area / Areaspline
  • Column / Bar
  • Pie / Donut (variablepie)
  • Scatter / Bubble
  • AreaRange / ColumnRange / Areasplinerange
  • Gauge / SolidGauge
  • Heatmap / Treemap / Sunburst / Treegraph
  • Boxplot / Errorbar / Waterfall / Funnel / Pyramid
  • Networkgraph / Sankey / Organization / Dependencywheel / ArcDiagram
  • Wordcloud / Venn / Timeline / Histogram / Bellcurve / PackedBubble
  • 3D variants, Cylinder, and more

Stock adds candlestick, OHLC, flags, indicators, etc.
Maps adds map, map bubble, geo heatmap, flowmap, etc.
Gantt for project timelines.

Full list: Chart types docs

Key classes / objects

  • Highcharts.Chart — main instance (update(), addSeries(), redraw(), exportChart(), destroy(), …)
  • Highcharts.Series — series (addPoint(), setData(), update(), remove())
  • Highcharts.Point — data point (update(), remove(), select())
  • Highcharts.Axis — axes (addPlotBand(), setExtremes(), update())
  • Also: Renderer, Color, Time, Tooltip, Legend, …

Class reference: api.highcharts.com/class-reference

Important features & modules

  • Styled mode — chart.styledMode: true + CSS for separation of design
  • Responsive — responsive.rules
  • Animation & events — chart, series, point, axis
  • Exporting / offline exporting / export-data
  • Accessibility, Boost (large data), drilldown, annotations, data module, sonification
  • v13+ — centralized palette, DataTable support, smarter labels, improved dark mode
