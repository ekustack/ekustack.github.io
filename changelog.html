Changelog

Release notes

What's new, fixed, and improved in ProvChart private versions. See the st-core.fscss repo for the open‑source core.

v1.1.0 August 19, 2026 Latest
  • New chart types: area(), hbar() (horizontal bar), stackedBar() (alias), scatter(), combo() (mixed bar + line).
  • Custom theming: Built‑in dark, light, midnight themes + custom theme overrides.
  • Stacked bar support: Pass stacked: true to bar() for cumulative bars.
  • Per‑series radius: Scatter charts now support radius per series.
  • ESM support: Full ES Module export for modern bundlers and <script type="importmap">.
  • Fixed: Axis labels now handle empty or missing values gracefully.
  • Fixed: Bar chart width calculation for uneven point counts.
v1.0.3 August 12, 2026
  • Fixed: ProvChart.line() handling of single‑point series now renders correctly.
  • Added: combine() helper to bundle multiple chart outputs into one HTML/CSS pair.
  • Changed: Default theme now uses #191629 for surface background (slightly deeper).
v1.0.2 August 5, 2026
  • Fixed: Gauge chart now correctly updates when update() is called with a new value.
  • Added: stat() helper for quick metric cards with optional delta indicator.
v1.0.1 July 28, 2026
  • Fixed: Multi‑series line charts now correctly apply distinct colors from the palette.
  • Fixed: clip-path animation for line charts — smoother transitions.
  • Changed: Drop shadow opacity reduced from 88 to 44 for subtler glow.
v1.0.0 July 20, 2026 Initial release
  • Initial release of ProvChart core with line(), bar(), and gauge() chart types.
  • CSS‑only rendering: All charts use clip-path and custom properties — no runtime JS.
  • Update API: Each chart returns an update() function for live data repaints.
  • Free & Pro tiers: Single‑series charts free; multi‑series and advanced types in Pro.
  • Open‑source core: Built on st-core.fscss — MIT licensed.
