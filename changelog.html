Changelog

Release notes

What’s new, fixed, and improved in ProvChart. Open-source core: st-core.fscss.

v1.3.1 August 25, 2026 Latest
  • ProvChart Runtime (separate tool): Optional progressive-enhancement script for HTML/CSS charts — tooltips, scroll reveal, legend focus, per-point hits, gauge/stat count-up. Not part of the core generate pipeline; does not run on pure SVG from generate-svg.
  • Package: npm: provchart-runtime@1.0.0 · GitHub · MIT · CDN via jsDelivr / unpkg.
  • Demos: Homepage, gallery, and generate workflow pages can load the runtime so charts enhanced after inject — zero per-chart setup beyond a script tag + optional window.ProvChartRuntimeConfig.
  • Docs: Runtime install, config, and SPA refresh/scan notes (see docs / runtime README). Core ProvChart chart types and API versions unchanged.
v1.3.0 August 24, 2026
  • SVG export API: POST /api/v1/generate-svg returns inline svg and dataUri — no file hosting, no third-party renderer. Counts toward the same monthly generation quota.
  • Pro Dashboard · SVG Export tab: Paste an API key, run generate-svg, preview markup, copy data URI, and see an equivalent curl command.
  • Adaptive chart builder: Form fields switch by type (series / hbar labels / multi-ring gauge) so payloads match the engine.
  • Multi-series radial gauge: Multiple rings with per-ring value and color; center label and thickness controls.
  • Fixed bar charts: Vertical bar accepts series + axisX (API shape). Multi-series and stacked layouts aligned with the line/area shell.
  • Fixed hbar styling: Horizontal bars use the same surface card, track, and radius treatment as other chart types.
  • Guides hub: Searchable /guides plus accessible charts, static embeds, email tips, and generator patterns.
  • Landing page: Pipeline-first story (compile → paint → index → update), problem → solution band, HTML/CSS + SVG outputs called out.
  • Docs examples: Developer API samples for both /generate and /generate-svg.
v1.2.0 August 20, 2026
  • Developer API: /api/v1/generate — generate HTML + CSS charts with an API key.
  • API keys: Create, list, and revoke keys from the Pro Dashboard.
  • Monthly limits: Pro = 500 gens/month · Business = 5,000 gens/month · free test generations available.
  • Business plan: $29/month with higher API and series limits.
  • Usage dashboard: Monthly used / limit / remaining in the Developer tab.
  • Soft errors: Clear messages for invalid key, plan required, and monthly limit reached.
  • Docs & pricing: Full API reference; Business row and API comparison on pricing.
v1.1.0 August 19, 2026
  • Chart types: area, hbar, stacked bar, scatter, combo.
  • Themes: dark, light, midnight + custom overrides.
  • Stacked bars: stacked: true on bar configs.
  • Scatter radius: Per-series point size.
  • ESM: Full ES module export for modern bundlers.
  • Fixed: Axis labels with empty/missing values; bar width on uneven series lengths.
v1.0.3 August 12, 2026
  • Fixed: line() with single-point series.
  • Added: combine() to merge multiple chart HTML/CSS outputs.
  • Changed: Default surface to #191629.
v1.0.2 August 5, 2026
  • Fixed: Gauge update() path.
  • Added: stat() metric cards with optional delta.
v1.0.1 July 28, 2026
  • Fixed: Multi-series line colors; smoother line clip-path animation.
  • Changed: Softer drop-shadow on series.
v1.0.0 July 20, 2026 Initial release
  • Initial release: line(), bar(), gauge().
  • CSS-only paint: Custom properties + clip-path — no chart-library runtime on the page.
  • Update API: Each chart can expose update() for live values.
  • Free & Pro: Single-series free; multi-series and advanced types on Pro.
  • Open-source core: st-core.fscss (MIT).
