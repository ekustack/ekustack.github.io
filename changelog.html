Changelog

Release notes

What's new, fixed, and improved in ProvChart. See the st-core.fscss repo for the open-source core.

v1.2.0 August 20, 2026 Latest
  • Developer API: New /api/v1/generate endpoint. Generate charts from your own backend using an API key.
  • API Keys: Create, list, and revoke API keys from the Pro Dashboard.
  • Monthly usage limits: Pro = 500 generations / month · Business = 5,000 generations / month.
  • Business plan: Now available at $29/month with higher API limits and series support.
  • Usage dashboard: See current month usage, remaining quota, and plan details in the Developer tab.
  • Soft error messages: Clear, user-friendly responses for limit reached, invalid key, and plan requirements.
  • Docs: Full Developer API reference added (authentication, endpoints, error codes, examples).
  • Pricing page: Updated with Business plan and API feature comparison.
v1.1.0 August 19, 2026
  • New chart types: area(), hbar(), stackedBar(), scatter(), combo().
  • Custom theming: Built-in dark, light, midnight themes + custom overrides.
  • Stacked bar support: Pass stacked: true to bar().
  • Per-series radius: Scatter charts now support radius per series.
  • ESM support: Full ES Module export for modern bundlers.
  • Fixed: Axis labels now handle empty or missing values gracefully.
  • Fixed: Bar chart width calculation for uneven point counts.
v1.0.3 August 12, 2026
  • Fixed: ProvChart.line() handling of single-point series.
  • Added: combine() helper to bundle multiple chart outputs.
  • Changed: Default surface background slightly deeper (#191629).
v1.0.2 August 5, 2026
  • Fixed: Gauge chart now correctly updates when update() is called.
  • Added: stat() helper for metric cards with optional delta.
v1.0.1 July 28, 2026
  • Fixed: Multi-series line charts now correctly apply distinct colors.
  • Fixed: Smoother clip-path animation for line charts.
  • Changed: Drop shadow opacity reduced for subtler glow.
v1.0.0 July 20, 2026 Initial release
  • Initial release with line(), bar(), and gauge().
  • CSS-only rendering: Charts use clip-path and custom properties — no runtime JS.
  • Update API: Each chart returns an update() function for live data.
  • Free & Pro tiers: Single-series free; multi-series and advanced types in Pro.
  • Open-source core: Built on st-core.fscss (MIT).
