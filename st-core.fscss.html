st-core.fscss MIT

st-core.fscss is a lightweight pure-CSS statistical dashboard / charting library for the FSCSS ecosystem. No JavaScript charting library, no SVG, no canvas — shapes are drawn with clip-path: polygon() driven by CSS custom properties. Optional JS only writes CSS variables; the browser paints everything.

  • Requires FSCSS v1.1.24+
  • MIT License
GitHub Live docs ProvChart (hosted)

Core idea

  • 8 fixed X positions: 0% 14% 28% 42% 57% 71% 85% 100%
  • Data lives in --st-p1 … --st-p8 (Y values)
  • You supply values on a natural 0–100 scale (100 = top). st-core inverts them to CSS coordinates.
  • Fill, line, and dots inherit the same variables from a parent container.

Installation

CDN / runtime (prototyping)

<script src="https://cdn.jsdelivr.net/npm/fscss@1.1.24/exec.min.js" async></script>
@import((*) from st-core)
/* or */
@import(exec(_init st-core))

CLI / production (recommended)

npm install -g fscss
fscss dashboard.fscss dashboard.css

Compiled output adds \~0.5 kb of pure CSS. Zero runtime, zero remote requests, excellent SEO.

Chart data injection

.chart {
  position: relative;
  height: 200px;
  overflow: hidden;
  @st-chart-points(20, 35, 33, 30, 48, 35, 66, 37)
}

Also available as @st-chart(...) with the same parameters.

Runtime update (JS optional)

const normalize = n => (100 - n) + '%';
function setChartData(el, values) {
  values.forEach((v, i) =>
    el.style.setProperty(`--st-p${i+1}`, normalize(v))
  );
}

Fill & line

Fill (area under line)

@st-chart-fill(.chart-fill)

Gradient from color-mix(in srgb, var(--st-accent) 35%, transparent) to transparent.

Line

@st-chart-line(.chart-line)
.chart-line { @st-chart-line-width(2.5px) }

Uses a forward + return clip-path polygon offset by --st-chart-line-width. Automatic drop-shadow glow.

Dots

Single manual dot

@st-chart-dot(.chart-dot, 71, 60)          /* x%, y-value */
@st-chart-dot(.chart-dot, 71, 60, 14px)    /* + size */

All 8 auto-positioned dots

@st-chart-dots(.chart-dot-, 7px)

Generates .chart-dot-1 … .chart-dot-8 that track --st-p{n}.

Grid & axes

@st-chart-grid(.chart-grid)           /* defaults 10 rows × 7 cols */
@st-chart-grid(.chart-grid, 8, 5)

@st-chart-axis-x(.x-axis)   /* flex row, space-between */
@st-chart-axis-y(.y-axis)   /* absolute, column-reverse */

Multi-line charts

One renderer, many series — override points (and color) per line:

@st-chart-line(.chart-line)

.line-1 { /* inherits container data */ }
.line-2 {
  background: #E8A030;
  @st-chart-points(10, 20, 16, 15, 66, 50, 80, 54)
}
.line-3 {
  background: #B840C8;
  @st-chart-points(5, 39, 20, 30, 27, 70, 60, 70)
}

UI components

@st-stat-card(.stat-card)
@st-cat-bar-fill(.bar-fill, 0)
<div class="stat-card">
  <div class="st-stat-label">Portfolio Value</div>
  <div class="st-stat-value">$84,201</div>
  <div class="st-stat-delta up">▲ +12.4%</div>
</div>

Delta classes: .up → green, .down → red. Bar width via --st-cat-bar-fill-range.

Source mixins (summary)

The full mixin definitions live in the repo: README and source tree github.com/fscss-ttr/st-core.fscss.

Key defines include:

  • @st-root — design tokens
  • @st-chart / @st-chart-points — data → --st-p1…p8
  • @st-chart-fill, @st-chart-line, @st-chart-line-width
  • @st-chart-dot, @st-chart-dots
  • @st-chart-grid, @st-chart-axis-x, @st-chart-axis-y
  • @st-stat-card, @st-cat-bar-fill
  • @st-container, @st-phone

Performance

  • Compiled: \~0.5 kb pure CSS
  • Runtime CDN: FSCSS engine \~10 kb + tiny cached .fscss
  • Pure HTML + CSS → excellent SEO (no hydration, no render-blocking chart JS)

Minimal example

<script src="https://cdn.jsdelivr.net/npm/fscss@1.1.24/exec.min.js" async></script>
<style>
@import((*) from st-core)
@st-root()
@st-chart-fill(.chart-fill)
@st-chart-line(.chart-line)

.chart {
  position: relative; height: 200px; background: var(--st-surface);
  border-radius: var(--st-radius-lg); overflow: hidden;
  @st-chart-points(20, 25, 21, 37, 30, 60, 27, 50)
}
</style>
<div class="chart">
  <div class="chart-fill"></div>
  <div class="chart-line"></div>
</div>
