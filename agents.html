MCP

Build charts with agents

provchart-mcp connects Claude Desktop and other MCP clients to ProvChart. Ask for a chart; the agent calls tools and gets real HTML/CSS or SVG—no Chart.js on the page.

npm package GitHub Get API key

Tools

Tool Returns Use for
provchart_generate html + css Pages and dashboards
provchart_generate_svg svg + dataUri README, docs, Markdown
provchart_explain Text Inject, ranges, runtime, errors (no API call)

Install

npm install -g provchart-mcp

# or
npx -y provchart-mcp

Set PROVCHART_API_KEY from Dashboard → Developer API. You can also pass apiKey on a single tool call.

Claude Desktop

Add to claude_desktop_config.json:

{
  "mcpServers": {
    "provchart": {
      "command": "npx",
      "args": ["-y", "provchart-mcp"],
      "env": {
        "PROVCHART_API_KEY": "pc_live_xxxxxxxx"
      }
    }
  }
}

Restart Claude Desktop, then ask for a chart in plain language.

Example prompt

“Generate a line chart of monthly signups: Jan 120, Feb 450, Mar 3200, Apr 8900, May 15400. Give me the SVG for my README.”

Values are real numbers—no need to scale to 0–100. Optional min / max pin the axis. 

{
  "type": "bar",
  "theme": "midnight",
  "series": [
    { "name": "2025", "color": "#8b7bff", "points": [40, 55, 48, 70] },
    { "name": "2026", "color": "#4fd8c4", "points": [35, 50, 62, 58] }
  ],
  "axisX": ["Q1", "Q2", "Q3", "Q4"]
}

Types

line · area · bar · stackedbar · hbar · scatter · combo · gauge

After the agent returns

HTML

document.getElementById("chart").innerHTML = html;
const style = document.createElement("style");
style.textContent = css;
document.head.appendChild(style);
// Optional: provchart-runtime@1.2.0 for tooltips only

SVG

Write a .svg file and embed with ![alt](./docs/charts/name.svg). Prefer files over huge data URIs on GitHub.

Errors

Code Meaning
INVALID_API_KEY Missing, revoked, or malformed key
SUBSCRIPTION_REQUIRED Plan inactive where required
MONTHLY_LIMIT_REACHED Monthly quota used (HTML and SVG share it)
