Enterprise

Data in. Markup out. At organization scale.

ProvChart stays a lightweight, pre-compiled path from metrics to HTML/CSS or SVG, no chart-library runtime required to paint. Enterprise is for teams that outgrow hosted Business limits (5,000 generations / month), need to self-host the rendering engine, or embed ProvChart inside a product, CMS, or site builder under a formal license.

What stays the same

Enterprise does not turn ProvChart into a heavy BI suite. The model remains:

  • Input: JSON (type, series, axis, theme, optional min/max)
  • Output: scoped HTML + CSS, or static SVG
  • Paint: browser-native CSS, optional runtime only for interaction
  • Integrate: API, CI Actions, MCP agents, or in-process engine
Fit: design systems, multi-tenant site builders, large marketing orgs, and internal platforms that generate thousands of chart instances per month.

Self-hosted rendering

Run the rendering engine inside your network or VPC so chart compilation never leaves your boundary.

  • Same data → markup contract as the public API
  • No dependency on provchart-api.devtem.org for generate
  • Fits regulated or air-gapped-style deployments (details under NDA)
  • You control scaling, logging, and key management

Enterprise license

Hosted Business is metered. Enterprise is a commercial license for redistribution or high volume use cases, including:

  • UI kits / site builders that generate charts for end customers
  • White-label or OEM embedding of the engine
  • Org-wide seats beyond self-serve plans
  • Custom MSA, invoicing, and support channels

Typical enterprise shapes

1. High-volume hosted

Stay on a ProvChart-managed API with a raised or uncapped generation allowance, invoicing, and shared Slack/email support, without operating the engine yourself.

2. Self-hosted engine

Package or container runs beside your services. Your orchestrator sends the same chart config; you receive HTML/CSS or SVG. Ideal when data residency or outbound-network policy blocks a public SaaS generate call.

3. Site builder / OEM

Your product lets customers place charts in pages or templates. License covers server-side generation at scale and clear terms for shipping ProvChart-powered output to your users.

What we usually align on

  • Expected gens / month (or peak concurrent renders)
  • Self-host vs private cloud API vs pure license
  • SVG + HTML output needs, themes, and chart types in use
  • Whether end users are internal only or external customers
  • Support hours, uptime expectations, update cadence
Open source: st-core.fscss remains MIT for CSS-native experimentation. Hosted API, commercial engine distribution, and OEM use are covered by ProvChart plans and Enterprise agreements, not by the MIT core alone.
